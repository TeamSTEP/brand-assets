06 // CREDITS — FOOTER
LOGO
grid
1280px max · 80px margins (40px each) · 12-col · 24px gutter · all sections share the same content-width container
hero
80vh (not 100vh) — leaves a peek of the Quest Board above the fold on tall screens, signalling there's content below. Pixel grid bg. 60/40 split. "Enter the Guild" is the ambient studio CTA, not a game CTA.
quest board
One card per game title. Meltdown: full-width featured, Platform Access panel inside splits Playable Now (green) vs Coming Soon (amber). Witch One: archive row, 60% opacity, single ghost CTA. sortOrder field in YAML controls display order.
platform CTAs
itch.io + Steam demo share "Playable Now" tier — same level, no hierarchy between them. Wishlist lives in "Coming Soon" tier, amber-coloured, clearly separated from demo tier. No "Meltdown Demo" naming — just "Meltdown" with tier labels inside the card.
social feed
Bluesky (AT Protocol API) · Substack (RSS) · YouTube (RSS) — fully branded. Discord (iframe, dark theme + CSS filter hue-rotate + scanline overlay). API vs WIDGET badge in tab chrome signals the difference intentionally.
video embeds
Local WebM loop in game card (no YouTube bot-check). VideoFacade.astro shows poster + play button; on click, lazily loads YouTube iframe. Keeps Lighthouse score clean.
animations
Scroll-triggered boot-in per section (glitch title → fade content). Dialogue typewriter on first view. Logo mark idle float. Custom cursor + pixel trail on desktop only. All wrapped in prefers-reduced-motion: none.
